### Подмена 'системных вызовов' с помощью LD_PRELOAD

Важно: нельзя подменить функции, определенные в программе,
т.к. они грузятся статически (а не динамически, как функции из libc)

Также нельзя подменить именно системные вызовы,
но можно подменить врапперы системных вызовов в libc.

Также нет гарантии соответствия реальных системных вызовов и врапперов.
Например, враппер sleep() на самом деле вызывает системный вызов clock_nanosleep()

---

В примере переопределяются все вызовы библиотечной функции sleep() и syscall()
