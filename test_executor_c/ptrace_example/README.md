### Используем ptrace для изменения поведения системных вызовов

uut.c - тестируемая программа

uut_runner.c - запускается и останавливается через SIGSTOP,
ждет пока его возобновит трассировщик, потом запускает uut через execvp

ptrace_disable_syscall.c - трассировщик, подключается к процессу uut_runner
и заменяет все системные вызовы clock_nanosleep на пустые


---

Вообще через ptrace можно заменить системные вызовы с помощью изменения регистров, но рабочего примера нет
